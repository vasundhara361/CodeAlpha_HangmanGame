# Task 1 — Hangman Game

A text-based word guessing game using a predefined list of five words.

## Concepts used
- `random` for selecting a word
- Lists and strings
- `while` loops and `if/elif` logic
- Input validation and sets for tracking guesses

## Run
```powershell
python main.py
```
Run this command from the `Task1_Hangman` directory, or from the project root use `python Task1_Hangman/main.py`.
